# Repository Guidelines

Finale Keyboard Actions is a public marketplace for distributing user-created actions for Finale Keyboard - a custom iOS keyboard. Read more about it in the main README.md

## Coding Style & Naming Conventions

Follow the following style for naming: types and general functions use `UpperCamelCase`; properties and functions who's sole purpose is to return values use `lowerCamelCase`. Keep feature-specific code near related files. Make focused edits and preserve existing formatting.

## Coding rules

- Don't change files or write code if you are not asked to.
- When writing code, perform minimal changes. Only write code that is necessary. Stick to the same coding style used in the repository.
